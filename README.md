# Špagato kelias

28 dienų lankstumo programa su animuotais pratimais. Tikslas: išilginis ir skersinis špagatas bei spyris į galvos aukštį.

- Atidaryk telefono naršyklėje: **https://lukaskivilius.github.io/claude/**
- „Pridėti prie pradžios ekrano“ (Add to Home Screen) – veiks kaip programėlė.
- Progresas saugomas tavo naršyklėje (localStorage).

Viskas viename faile `index.html`, be priklausomybių.
